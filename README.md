# Akamine & Associados — Advocacia e Assessoria Jurídica

Landing page institucional para o escritório de advocacia **Akamine & Associados**, localizado em **Bragança Paulista, SP**.

---

## Sobre o Projeto

Este site foi desenvolvido como parte do portfólio de demonstração da **Akamine Web Studio**, estúdio especializado em criação de sites profissionais, landing pages e soluções digitais para empresas e profissionais liberais em Bragança Paulista e região.

O projeto reflete a identidade única de um escritório de advocacia: **autoridade, confiança, clássico e elegância minimalista**. Cada detalhe foi pensado para transmitir credibilidade e sofisticação ao público-alvo.

**Desenvolvido por:** [JulioAkaminee](https://github.com/JulioAkaminee)

---

## Características

- **Design responsivo** — adaptado para desktop, tablet e mobile
- **Animações ricas** — AOS (Animate On Scroll) para transições suaves e envolventes
- **Imagens reais do nicho** — fotografias profissionais de ambientes jurídicos e corporativos
- **Tipografia elegante** — EB Garamond para títulos e Lato para corpo de texto
- **Paleta de cores exclusiva** — rosa profundo (#DB2777) + dourado elegante (#A16207) + fundo rosa claro (#FDF2F8)
- **Ícones vetoriais** — Lucide Icons para consistência visual
- **Navegação fixa inteligente** — navbar que muda de aparência ao rolar a página
- **Menu mobile** — slide-in para dispositivos móveis
- **Formulário de contato** — com validação visual e estilo glassmorphism
- **Botão flutuante WhatsApp** — para contato direto e rápido
- **SEO-friendly** — meta tags e estrutura semântica otimizadas

---

## Seções do Site

1. **Hero** — Apresentação impactante com imagem de escritório profissional, estatísticas e chamadas para ação
2. **Estatísticas** — Números que demonstram experiência e credibilidade (15+ anos, 2.500+ casos, 98% de sucesso)
3. **Áreas de Atuação** — Cards interativos para Cível, Trabalhista, Empresarial, Previdenciário, Tributário e Assessoria Jurídica
4. **Diferenciais / Experiência** — Destaques do escritório com layout assimétrico e imagem destacada
5. **Depoimentos** — Cards de clientes com avaliações em estrelas e fotos reais
6. **Consulta Inicial Gratuita** — Formulário de contato com informações completas do escritório
7. **Footer** — Links rápidos, redes sociais e dados institucionais

## Como Visualizar

Abra o arquivo `index.html` diretamente em qualquer navegador moderno. Não requer instalação de dependências — todas as bibliotecas são carregadas via CDN.

```bash
# Navegue até a pasta do projeto
cd /opt/data/sites/akamine-associados

# Abra no navegador (Linux)
xdg-open index.html

# Ou em macOS
open index.html

# Ou em Windows
start index.html
```
